Занимаюсь разработкой робототехнических систем (от проектирования до программирования) и прикладного программного обеспечения (backend, embedded). Сейчас настраиваю собственный вычислительный кластер под задачи лаборатории. Веду репозиторий ещё со школы, где и учился своим первым языкам программирования (C++, Python, C#, Lua).
